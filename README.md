# Тестове завдання: таблиця співробітників

Застосунок показує таблицю на кілька тисяч співробітників з пошуком, фільтрами, сортуванням, виділенням рядків, редагуванням, статистикою та модальним вікном з деталями.

Він працює, але повільно: таблиця довго рендериться, інтерфейс підвисає під час взаємодії, а код важко підтримувати.

## Запуск

```bash
npm install
npm run dev
```

## Проблеми швидкодії

- `Row` був оголошений всередині `App`, тому на кожен рендер перестворювались всі 5000 рядків. винесено в `EmployeeRow` + `memo`
- годинник, hover і інпут редагування ререндерили весь `App`. годинник окремим компонентом, hover на css, чернетка в `EditingCell`
- частка і ранг рахувались для кожного рядка по всьому списку, тепер один раз на список
- `filtered` рахувався в useEffect через setState, тому кожна зміна фільтра давала два рендери. тепер `useMemo`
- `calcStats` викликався на кожен рендер `App` і копіював всі 5000 рядків через `JSON.parse(JSON.stringify())` та сортував їх заради одного найкращого. тепер `useMemo` і один прохід
- пошук через `JSON.stringify` на кожну літеру. тепер індекс + `useDeferredValue`
- `Intl` форматтери створювались на кожен виклик, тепер один раз
- виділення було масивом, тепер `Set`
- рендерило 5000 рядків співробітників в DOM, тепер віртуалізація

## Баги (які запам'ятав)

- редагування змінювало не той рядок (брався індекс з відфільтрованого списку), тепер по id
- дабл клік відкривав модалку замість редагування, інпут губив фокус
- після видалення і скидання не чистилось виділення
- в строгому режимі при перезавантаженні затирались збережені дані, битий localStorage ломав додаток
- інтервал годинника не чистився
- модалка не закривалась по Esc

## Бібліотеки

- `@tanstack/react-virtual` для віртуалізації
- `zustand` в основному щоб уникнути проп дріллінг
- `immer` для стору, мутабельний стиль замість спредів
- `classnames` просто чистіше код

## Що вирішив не робити

- css лишив глобальним, сенсу переписувати не було. в реальному проєкті були б scss модулі
- клік по "Посада" і "Зарплата" не відкриває модалку, інакше дабл клік не працюватиме
