# Тестове завдання: таблиця співробітників

Застосунок показує таблицю на кілька тисяч співробітників з пошуком, фільтрами, сортуванням, виділенням рядків, редагуванням, статистикою та модальним вікном з деталями.

Він працює, але повільно: таблиця довго рендериться, інтерфейс підвисає під час взаємодії, а код важко підтримувати.

## Запуск

```bash
npm install
npm run dev
```

## Що потрібно зробити

1. Зробити так, щоб застосунок працював швидко й без підвисань: прокрутка, наведення, пошук, фільтри, сортування, виділення та редагування мають відгукуватися миттєво.
2. Відрефакторити код: розбити на компоненти, хуки та модулі з чіткою відповідальністю, прибрати дублювання, навести лад з типами TypeScript.
3. Знайти й виправити баги, якщо натрапите на них.
4. Зберегти весь наявний функціонал.

Можна додавати бібліотеки, якщо зможете пояснити, навіщо вони потрібні. Можна змінювати структуру проєкту як завгодно.

## Що надіслати

- Посилання на репозиторій з історією комітів.
- Короткий опис у README: які проблеми знайшли, як їх виправили і як перевіряли результат (наприклад, React Profiler або Performance у DevTools до і після).

Орієнтовний час виконання: 4–6 годин.
